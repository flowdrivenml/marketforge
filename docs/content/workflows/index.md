# Workflows

Start with the outcome you need. For the objects and guarantees shared by these workflows, see [MarketForge concepts](../concepts/index.md). The [Bybit quick start](../getting-started/quickstart.md) shows the full route from provider archive to inspected Parquet.

| Task | Guide |
| --- | --- |
| Find a market or compare eligibility, volume, and turnover | [Market discovery, statistics, and rankings](markets/index.md) |
| Preview source coverage and download provider archives | [Historical acquisition](acquisition/historical-data.md) |
| Check managed copies, verify bytes, or review cleanup | [Raw storage](storage.md) |
| Describe venue and instrument identity and attach applicable terms | [Catalogue and specifications](catalogue/index.md) |
| Bring existing bytes into the managed workflow | [External recordings](acquisition/external-data.md) |
| Map supported raw formats into canonical trades or book observations | [Profile authoring](normalization/author-profile.md) |
| Turn managed inputs into canonical output | [Normalization](normalization/index.md) |
| Build an ordered timeline from normalized files | [Merge](merge.md) |
| Express price or notional in another quote currency | [Conversion](conversion.md) |
| Orchestrate acquisition, normalization, and merge | [Historical pipeline](pipeline.md) |
| Inspect file contents, coverage, or lineage | [CLI dataset inspection](inspection/datasets.md) and [Python notebooks](../research/notebooks.md) |
| Inspect execution results and retained evidence | [Runs](inspection/runs.md) |
| Browse or launch operations interactively | [Forge workspace](forge-tui.md) |

For an interrupted run or environment problem, go to [troubleshooting and recovery](../maintenance/index.md). For exact fields and output contracts, use the [reference](../reference/index.md).
