# Contributing to MarketForge

Forge is the Python application for configuration, orchestration, the terminal workspace, and dataset access. The Rust Engine processes historical and live data. Start with the [developer overview](https://flowdrivenml.github.io/marketforge/development/) and [local setup](https://flowdrivenml.github.io/marketforge/development/setup/).

- Report bugs in [the issue forms](https://github.com/flowdrivenml/marketforge/issues/new/choose). Include the version, platform, reproduction steps, and relevant logs with credentials and local paths removed. Report vulnerabilities through the [security policy](SECURITY.md).
- Use the matching issue form for feature requests, financial research proposals, data sources, and documentation changes. Bring questions and early ideas to [GitHub Discussions](https://github.com/flowdrivenml/marketforge/discussions).
- Submit focused pull requests and describe the behavior changed and the checks you ran. Follow the [testing guide](https://flowdrivenml.github.io/marketforge/development/testing/) for the affected area. For documentation, use the [Zensical build and link checks](docs/README.md).
