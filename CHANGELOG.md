# Changelog

## 0.1.0 — 2026-11-25

- First source release of the operational historical workflow. Discover and acquire supported archives, register external recordings, normalize and merge events, and optionally convert quote values.
- Run reusable historical recipes from the CLI or Forge workspace. Browse market metadata, registered datasets, and retained execution reports.
- Discover and inspect Parquet datasets in Python and Jupyter. Read exact values with Arrow or query compatible projections with Polars.
- Standard installation supports Ubuntu, Debian, and supported macOS configurations. Conversion publication currently requires Linux.
